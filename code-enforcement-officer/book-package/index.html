About this Code Enforcement Officer package

Code enforcement work requires a balance of technical code knowledge, communication skill, professional judgment, and procedural awareness. A code enforcement officer may inspect properties, respond to complaints, evaluate unsafe or unsanitary conditions, issue notices, document violations, communicate with owners and occupants, coordinate with other departments, and support fair, consistent compliance efforts. This exam book package helps candidates prepare with references that support both the property maintenance code side and the enforcement strategy side of the profession.

Exam Details

The ICC Code Enforcement Officer exam is identified as CE-O. ICC lists the exam with 50 questions and a 2.5-hour duration. The ICC Code Enforcement Program describes the Code Enforcement Officer role as a field professional who helps foster safe, healthy, and attractive communities by working with residents, property owners, and business owners to achieve compliance through education, inspection, mediation, and formal enforcement action.

ICC’s current Code Enforcement Program also states that completion of the Code Enforcement Technician credential is a prerequisite for the Code Enforcement Officer credential. Candidates preparing for the CE-O exam should make sure their ICC credential path is complete and that they follow the registration instructions in their myICC account.

The exam preparation focus should include property maintenance standards, code administration, inspection procedures, enforcement documentation, notices and orders, unsafe structures, sanitation, occupancy, exterior property conditions, plumbing facilities, mechanical systems, electrical safety, fire safety, legal process awareness, communication, case management, and community compliance strategies.

Students should also study the practical role of the code enforcement officer. The job often involves working with the public, communicating code requirements clearly, documenting conditions, preserving procedural fairness, coordinating with other departments, and choosing appropriate compliance tools. Good preparation should connect the written code to real field conditions and responsible enforcement practice.

Open Book Test

The Texas Code Enforcement Officer (ICC - CE-O) exam is an open book test. Open book testing means candidates may use approved references during the exam, but it does not remove the need for preparation. The strongest candidates know how to use the books efficiently, locate the correct section, understand definitions, read requirements carefully, and apply the reference material to practical enforcement scenarios.

The 2024 International Property Maintenance Code should be studied as the primary code reference. Candidates should become familiar with the table of contents, chapter organization, scope and administration provisions, definitions, general requirements, light and ventilation rules, occupancy limitations, plumbing facility requirements, mechanical and electrical provisions, fire safety requirements, unsafe structure provisions, notices, orders, appeals, and enforcement procedures.

Strategic Code Enforcement should be used to strengthen understanding of the professional enforcement process. Students should review code enforcement operations, investigation practices, remedies, administrative enforcement, civil and criminal enforcement concepts, complex case handling, proactive strategies, interdepartmental coordination, community goals, and defensible decision-making.

Open book study should include timed lookup practice. Candidates should read a question, identify whether it is asking about a code requirement, enforcement procedure, field condition, notice, case strategy, or administrative issue, then move to the correct reference. This habit builds speed and reduces the risk of searching through the wrong section during the exam.

How does the Code Enforcement Officer exam work?

The Code Enforcement Officer exam is set by a Texas city or by TDLR rather than by a statewide contractor board. The city or agency approves you, then the exam is scheduled with ICC or PSI.

  • The PSI exam has 70 scored items in 105 minutes, costs $50 and is closed book.
  • Registration costs $100 and lasts 2 years, with 12 hours of continuing education before each renewal.
  • Texas does not license general contractors at the state level; the Texas Residential Construction Commission was abolished in 2009.
  • Cities set their own registration rules, and some, such as San Antonio, require an ICC exam for certain trades.
  • San Antonio sign operators need a passing ICC exam, a $45,000 bond and $1,000,000 in general liability insurance.
  • Texas code enforcement officers register with TDLR after the TEEX course and a closed-book PSI exam that costs $50.
